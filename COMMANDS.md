# IntelliQuery AI - Commands List

This file lists the available commands for the IntelliQuery AI project.

## Setup
Automation script to set up the environment, install dependencies, and prepare the database.
```powershell
./setup.ps1
```

## Running the Application
Starts the Streamlit-based user interface.
```powershell
streamlit run app.py
```

## Testing
Runs the full test suite using Pytest.
```powershell
pytest tests/ -v
```

## Environment Configuration
Example of how to run or check Ollama (if using local mode).
```powershell
ollama run llama3
```
